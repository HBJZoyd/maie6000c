# ADR0006 — Accept the final system through a real A100 run

Date:28 November2026. Status: accepted and executed.

The initial A800 provisioning plan did not yield a ready resource in the working window. The user approved a same-region A100 backup and then limited work to A100. All final compute results refer to A100, not A800.

The private image retained the existing environment; data moved separately. With explicit permission the source was temporarily stopped for platform copying and restored in no-GPU mode afterward. All copied-file hashes passed before target repair. A genuine Mongo snapshot rebuilt the empty vector index with rollback proof. Adapters, not original source core, absorb schema incompatibilities.

Acceptance requires HTTP202/queued SQL, a separate worker, actual generation, valid source envelopes, saved results and restart survival. The user subsequently requested preservation of the old recorded demo. Its original run evidence, adapters and an exact historical report/PPT archive are retained beside the new live evidence. Private weights/manual/database files remain outside Git. Dated live readiness is not permanent hosting; factual accuracy and public access controls require separate work.
